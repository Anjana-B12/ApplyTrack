# ApplyTrack – Job Application Tracker

ApplyTrack is a web-based job application tracking system that helps users organize and manage their job applications in one place.

## Features

- **User Authentication** – Register, log in, and log out securely.
- **Dashboard** – View an overview of job applications.
- **Add Applications** – Store company names, job positions, application dates, and other details.
- **Edit Applications** – Update existing application details.
- **Delete Applications** – Remove applications with a confirmation prompt.
- **Search** – Search applications by company name or job position.
- **Filter** – Filter applications based on their status.
- **Sorting** – Sort applications by newest, oldest, or company name.
- **Pagination** – Browse applications across multiple pages.
- **Application Statistics** – Track application statuses through dashboard summaries.

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/Anjana-B12/ApplyTrack.git
   ```

2. Navigate to the project directory:

   ```bash
   cd ApplyTrack
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Make sure MongoDB is running locally.

5. Start the application:

   ```bash
   node app.js
   ```

6. Open your browser and visit:

   `http://localhost:3000`
